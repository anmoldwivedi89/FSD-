## 📖 Overview

This repository is curated and maintained by **Anmol Dwivedi** as a complete personal knowledge base and structured curriculum for **Full-Stack Web Development (FSD)**. Every concept is organized incrementally — from low-level markup to full-stack reactive apps and database pipelines.

- 🧱 **Frontend Core**: Semantic HTML5, modern CSS3 layout engines (Flexbox, Grid), media queries, and Bootstrap 5 components.
- ⚙️ **JavaScript Mastery**: ES6+ fundamentals, closures, higher-order array functions, DOM manipulation, asynchronous programming, and Fetch API.
- 🍃 **Database Management**: MongoDB queries, data aggregation pipelines, nested document operations, and CRUD operations.
- 🚂 **Server-Side Engineering**: Express.js 5 modular routing, controllers, MVC pattern, middleware, and Mongoose ODM integration.
- ⚛️ **Modern React**: React 19 with Vite, functional component architecture, custom & built-in hooks (`useState`, `useEffect`), React Router v7, and Global Context API.

## ⚡ Getting Started

Follow these steps to run any part of this repository on your local machine:

### 1. Clone the Repository

```bash
git clone https://github.com/anmoldwivedi89/FSD-.git
cd FSD-
```

---

### 2. Frontend Fundamentals (`HTML-CSS-JS/`)

- No build tools or package managers required.
- Open any `.html` file directly in your browser or use the **VS Code Live Server** extension for real-time live reloading.

---

### 3. MongoDB Practice (`MongoDB/`)

Run any script using the MongoDB Shell (`mongosh`) or MongoDB Compass:

```bash
# Connect to local MongoDB instance and run a query file
mongosh "mongodb://localhost:27017/collegeDB" < "MongoDB/1 MongoDbQueries.js"
```

---

### 4. Express Server (`Express/`)

```bash
# Navigate to Express backend
cd Express

# Install dependencies
npm install

# Start server
node index.js
# Or with nodemon for auto-restart
npm run dev
```

The server will start on `http://localhost:5000` (or your configured port).

---

### 5. React Application (`React/myFirstApp/`)

```bash
# Navigate to the React Vite project
cd React/myFirstApp

# Install dependencies
npm install

# Start development server
npm run dev
```

Open `http://localhost:5173` in your browser.

**Other available React scripts:**
```bash
npm run build     # Build production bundle
npm run preview   # Preview the production build locally
npm run lint      # Run ESLint validation
```
